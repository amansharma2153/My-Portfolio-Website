*If your current website uses embedded CSS and JavaScript inside `index.html`, the separate `style.css` and `script.js` files are optional until you split the code into separate files.*

## Run Locally

1. Download or clone the GitHub repository.
2. Ensure `index.html`, the CSS and JavaScript files (if separate), and `Aman_Sharma_Resume.pdf` are in the correct locations.
3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
4. Test the navigation, project links, resume download, and contact form.

## Deploy Online with Render

1. Create a GitHub repository for your portfolio.
2. Upload the website files and resume PDF.
3. Sign in to Render and select **New → Static Site**.
4. Connect your GitHub repository.
5. Set the build command to blank if the site requires no build process.
6. Set the publish directory to `.` when your `index.html` is in the repository root.
7. Deploy the website and open the public URL provided by Render.
